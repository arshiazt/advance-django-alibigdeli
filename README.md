# Blog Project

This project is an educational Django blog project developed as part of an advanced Django course by **Ali Bigdeli**.

The main goal of this project was to learn and practice advanced Django concepts, along with exploring Django REST Framework and related tools and technologies.

## Technologies & Concepts

- Django
- Django REST Framework (DRF)
- Generic API Views
- Different types of Generic Views in DRF
- SQLite
- Celery
- Redis
- Pytest
- Swagger
- Docker
- Locust

## Features & Learning Topics

- Building a blog application with Django
- Working with Django REST Framework
- Implementing different types of Generic API Views
- Working with Celery for background tasks
- Using Redis as a message broker and cache backend
- Implementing caching in Django
- Writing automated tests using Pytest
- API documentation and testing with Swagger
- Dockerizing the project
- Load and performance testing with Locust

## Purpose

This project was created primarily for learning and practicing advanced Django and Django REST Framework concepts while working with additional tools such as Redis, Celery, Docker, Pytest, Swagger, and Locust.
